## 📂 Estrutura do Projeto

O projeto está organizado com os seguintes arquivos principais:

* `main.c` — Arquivo principal contendo o fluxo de execução do programa.
* `Calculos.c` — Módulo responsável por realizar os cálculos e lógicas centrais.
* `Dor_d_cabeca.h` — Arquivo de cabeçalho (`header`) com definições e estruturas de dados auxiliares.

---

## 🚀 Como Executar

Caso queira compilar e rodar o projeto em sua máquina, siga os passos abaixo (utilizando um compilador C compatível, como o GCC):

1. Clone o repositório:
```bash
git clone <url-do-repositorio>

```

2. Navegue até o diretório do projeto:
```bash
cd Desafio-Joana-main/UT\ Desafio-Joana-main/

```

3. Compile os arquivos C:
```bash
gcc main.c -o programa.exe

```

4. Execute o programa:
```bash
./programa
